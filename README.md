# ClearFlow Free

30-day, feature-limited trial installers for macOS and Windows. This repository distributes free installers only; source code and personal/full builds remain private.

The earlier nonexpiring preview has been withdrawn. Download verified replacement trial installers from [Releases](https://github.com/josuenovar/ClearFlow-Free-Downloads/releases).

- One active task, Follow-Up, Pulse and Orbit at a time.
- Complete an item before adding another. Editing and completed history remain available.
- Google Calendar and Outlook connections require the full version.
- The trial lasts 30 days from server activation, with reminders at seven and three days remaining.
- Reinstallation or another download does not restart the trial. Repeated email, installation identity or network address does not create a new 30-day window.
- Internet access is required for activation and periodic verification. Saved data is preserved after expiry.
- Full-version purchases are not available yet. A confirmed account is not a paid license.
- macOS: Intel and Apple Silicon. Windows: x64.

These preview installers are not notarized or signed with a production publisher certificate. A ClearFlow account is required to use the app.
