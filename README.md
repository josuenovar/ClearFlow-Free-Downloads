# ClearFlow Free

Feature-limited preview installers for macOS and Windows. This repository distributes free installers only; source code and personal/full builds remain private.

Download the latest preview from [Releases](https://github.com/josuenovar/ClearFlow-Free-Downloads/releases).

- One active task, Follow-Up, Pulse and Orbit at a time.
- Complete an item before adding another. Editing and completed history remain available.
- Google Calendar and Outlook connections require the full version.
- No time-based trial expiration. Full-version purchases are not available yet.
- macOS: Intel and Apple Silicon. Windows: x64.

These preview installers are not notarized or signed with a production publisher certificate. A ClearFlow account is required to use the app.
